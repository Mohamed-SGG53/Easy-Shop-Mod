# 🧵 Easy-Shop-Mod (Official Mapping Version)

## English

This is the **latest stable standalone version** of the mod, fully working on:

* **Minecraft Java 1.21.11**
* **Fabric Loader**

🔹 **Mod Version:** `V7.1.4`

🔹 This version is based on **Official Mojang Mappings**

🔹 This is the **final standalone release version**

---

### 🛠️ Build Locally

To build the mod on your device:

```bash
gradle wrapper
```

Then run:

```bash
gradlew build
```

The compiled mod file will be generated in:

```
build/libs
```
