# 🧵 Easy-Shop-Mod (Official Mapping Version)

## English

This is the **development version** of the mod based on **Official Mojang Mappings**.

It is currently **under active development** and is not the final stable release.

🔹 Target Minecraft versions: **1.21.11 and above**
🔹 Supports **Fabric (current stage)**
🔹 Forge support will be added in a future update
🔹 Mod Version: `V5.0.0-dev`

### 🚧 Development Status

This version is being built to:

* Ensure compatibility with **newer Minecraft updates (above 1.21.11)**
* Improve long-term stability using Official Mappings
* Prepare for multi-loader support (Fabric → Forge)

### 🛠️ Build Locally

To build the project on your device:

```bash id="om1"
gradle wrapper
```

Then run:

```bash id="om2"
gradlew build
```

The output file will be located in:

```id="om3"
build/libs
```

### ⚠️ Note

This version is still in development and may contain bugs or incomplete features.
