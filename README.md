# 🧵 Easy-Shop-Mod (Yarn Version)

## English

This is the **latest stable version** of the mod, fully working on:

* **Minecraft Java 1.21.11**
* **Fabric Loader**

🔹 **Mod Version:** `V5.0.0`
🔹 This version is based on **Yarn Mappings**

### 🛠️ Build Locally

To build the mod on your device:

```bash
gradle wrapper
```

Then run:

```bash
gradlew build
```

The compiled mod file will be generated in:

```
build/libs
```

### 🔗 Mod Link

Download the mod from:
https://modrinth.com/mod/easy-shop-mod

لبناء المود على جهازك:

```bash
gradle wrapper
```

ثم نفّذ:

```bash
gradlew.bat build
```

سيتم إنشاء ملف المود داخل مجلد:

```

```
